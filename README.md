# # Wearable EMG-Based Morse Code Silent Communication with AES Security

A wearable communication system that uses Electromyography (EMG) signals to detect intentional muscle movements, convert them into Morse code, and securely transmit the decoded message using AES encryption.

## 📌 Overview

The project proposes a silent communication system using EMG signals generated by intentional muscle movements.

The system captures muscle activity through an EMG sensor, processes the signal, identifies predefined muscle activation patterns, and maps them to Morse code characters.

The resulting message is secured using AES encryption before transmission, providing an additional layer of communication security.

## 🎯 Objectives

- Enable silent communication using muscle activity.
- Acquire and process EMG signals.
- Detect intentional muscle activation patterns.
- Convert detected patterns into Morse code.
- Decode Morse code into readable characters.
- Protect transmitted information using AES encryption.
- Provide a wearable and discreet communication approach.
